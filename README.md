# 🚗 QuickDashCam (액션캠·블랙박스 주행 영상 스마트 병합 & AI 구간 스킵)

자동차 대시보드에 설치한 액션캠(GoPro, DJI Osmo Action, Insta360, 일반 블랙박스 등)의 여러 주행 영상들을 **시간순으로 자동 정렬**하고, **신호대기(정차)**나 **장시간 고속도로 직진**처럼 화면 변화가 거의 없는 구간을 자동으로 감지하여 **배속(타임랩스) 또는 점프컷(잘라내기)** 처리해 하나의 깔끔한 완성본 영상으로 합쳐주는 크로스 플랫폼 데스크톱 애플리케이션입니다.

---

## ✨ 주요 기능

### 1. 📂 스마트 시간순 자동 정렬 (`src/sorter.py`)
- 영상 컨테이너 메타데이터의 `creation_time` 촬영 시각, 파일명 내 날짜 패턴(`VID_YYYYMMDD_HHMMSS`), 파일 수정 시각을 종합 분석하여 정확한 시간순으로 자동 정렬합니다.
- **고프로(GoPro) 분할 챕터 완벽 대응**: `GX010042.MP4`, `GX020042.MP4`처럼 챕터 번호가 앞에 붙는 액션캠 파일명 규칙을 자동 인식하여 촬영 순서대로 정렬합니다.
- GUI 목록에서 항목 선택 후 위/아래(`▲`/`▼`) 버튼으로 언제든 수동 순서 조정 및 개별 파일 제외가 가능합니다.

### 2. ⚡ 초고속 하드웨어 가속 & 2중 화면 변화 감지 (`src/analyzer.py`, `src/ffmpeg_utils.py`)
- **GPU 디코딩 & VRAM 내부 리사이징 (`CUDA NVDEC + scale_cuda` / `D3D11VA` / `VideoToolbox` / `VAAPI`)**:
  - 4K/2.7K/1080p 고해상도 영상을 하드웨어 가속으로 디코딩하며, GPU 메모리 내부에서 `160×90` 축소 처리를 진행하여 CPU 점유율을 획기적으로 낮추고 분석 속도를 극대화했습니다.
  - 비참조 B-프레임 스킵(`-skip_frame noref`) 및 1초당 1~2프레임 다운샘플링 분석.
- **신호대기 / 정차 감지 (`STOP`)**:
  - 하늘 및 보닛/대시보드를 마스킹하고 근거리 노면/차선 영역(ROI)의 픽셀 변화량과 위상 상관을 분석하여, 교차로에 횡단 차량이나 보행자가 지나가더라도 내 차가 정차 중이면 정확하게 정차 구간으로 판별합니다.
- **고속도로 직진 / 단조 주행 감지 (`STRAIGHT`)**:
  - 차량 주행 중 수평 조향 변화량, 전방 소실점(Vanishing Point), 16×9 저주파 구도 변화량을 종합 추적하여 급커브나 차선 변경이 없는 단조로운 직선 도로 주행 구간을 자동 감지합니다.
- **민감도 실시간 즉시 재분류**:
  - 최초 1회 영상 분석 후 프레임별 변화량 점수가 메모리에 캐싱되므로, 감지 민감도(%)나 최소 지속 시간(초) 슬라이더를 변경하면 영상을 재스캔할 필요 없이 **즉시(0.01초)** 구간이 다시 계산됩니다.

### 3. 🎬 실시간 스트리밍 재생 & 타임라인 줌/패닝 (`src/gui.py`)
- **실시간 순차 스트리밍 프리뷰 (`PlaybackWorker`)**:
  - 프레임 건너뜀 없이 일반 동영상 플레이어처럼 30fps 부드러운 실시간 재생을 지원합니다.
  - `0.5x`, `1.0x (기본)`, `2x`, `4x`, `8x` 배속 재생 프리뷰 선택 지원.
- **타임라인 확대/축소 및 이동 (Zoom & Pan)**:
  - 마우스 휠 스크롤로 타임라인 확대/축소 (`1배 ~ 최대 100배`), 마우스 휠 클릭 드래그 또는 `Shift + 휠`로 좌우 패닝.
  - 상단 미니맵 내비게이션 바를 통해 2시간 이상의 장시간 주행 영상에서도 원하는 위치를 한눈에 파악하고 즉시 이동할 수 있습니다.

### 4. 🔎 검출 구간 리뷰 워크플로우 (`[🔎 검출 구간 리뷰]` 탭)
- 감지된 신호대기 및 단조 주행 구간들을 순서대로 탐색하며 사용자가 직접 유지/복원/삭제 여부를 결정할 수 있습니다.
- **리뷰 탭 전용 키보드 단축키**:
  - `[1]`: 스킵 유지 (`SKIP`)
  - `[2]`: 1배속 일반 주행 복원 (`NORMAL`)
  - `[3]`: 완전 삭제 (`MANUAL_CUT`)
  - `[` / `]`: 이전 / 다음 검출 구간으로 이동 (해당 구간으로 타임라인 자동 줌 & 이동)
  - `P`: 현재 검출 구간 미리보기 재생
  - `N`: 다음 미검토 구간으로 자동 이동

### 5. ✂️ 통합 타임라인 구간 편집 & 수동 컷
- 타임라인 바 우클릭 드래그(또는 `Shift + 좌클릭 드래그`), 또는 `[🚩 시작점(I)]` / `[🏁 끝점(O)]` 버튼을 통해 특정 구간을 지정할 수 있습니다.
- `[✂️ 선택 구간 잘라내기 (Delete)]`로 불필요한 사생활 노출 구간이나 주차 영상을 즉시 삭제 처리할 수 있습니다.
- `[♻️ 일반 주행(1x) 복원]`으로 자동 감지된 스킵 구간을 일반 주행으로 되돌릴 수 있으며, `[↩ 되돌리기 (Ctrl+Z)]`를 지원합니다.

### 6. 🎛️ 풍부한 인코딩 & 내보내기 옵션 (`src/processor.py`)
- **화질 프리셋**:
  - `원본 유지급 최고화질 (무손실에 가까움 · CRF 14 / CQ 15, 오디오 256kbps)`
  - `고화질 (원본 수준 권장 · CRF 18 / CQ 19, 오디오 192kbps)`
  - `표준 화질 (화질·용량 균형 · CRF 22 / CQ 23)`
  - `저용량·고속 (빠른 압축 · CRF 27 / CQ 28)`
- **해상도**: `원본 해상도 유지`, `4K UHD (3840×2160)`, `2.7K QHD (2560×1440)`, `1080p FHD`, `720p HD`
- **프레임 레이트**: `원본 FPS 유지`, `60fps`, `30fps`, `24fps`
- **비디오 코덱**: `H.264 (AVC - 호환성 최우선)`, `H.265 / HEVC (고효율·4K 압축 권장)`
- **오디오 처리**:
  - 정상 구간 유지 / 스킵 구간 음소거
  - 배속 구간도 오디오 속도 높여 함께 재생 (`atempo` 음높이 보정)
  - 전체 음소거
- **배속 배지 오버레이**: 배속 재생 구간 우측 상단에 반투명 박스 및 `>> 8x` 배지 표시 지원.

## 🖥️ 플랫폼 지원 (Cross-Platform)

QuickDashCam은 Windows, macOS, Linux 전 플랫폼에서 동일하게 동작합니다.

- **Windows**: NVIDIA CUDA/NVDEC/NVENC, Direct3D 11 (`d3d11va`), Intel QSV, AMD AMF
- **macOS**: Apple Silicon (M1~M4) 및 Intel Mac의 **VideoToolbox** (`h264_videotoolbox`, `hevc_videotoolbox`)
- **Linux**: NVIDIA NVENC 및 Intel/AMD **VAAPI** (`h264_vaapi`, `hevc_vaapi`)
- **CPU 폴백**: 하드웨어 가속 장치가 없는 환경에서도 멀티스레드 CPU 코덱(`libx264`, `libx265`)으로 100% 정상 완주

## 🚀 설치 및 실행 방법

### 요구 사항
- Python 3.9 이상
- Windows 10/11, macOS 12+, 또는 Linux

### 1. 저장소 복제 (Clone)
```bash
git clone https://github.com/kai4th/quick_dash_cam.git
cd quick_dash_cam
```

### 2. 가상환경 생성 및 의존성 설치
- **Windows**:
  ```powershell
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  ```
- **macOS / Linux**:
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  ```

### 3. 프로그램 실행
- **Windows**: 폴더 내 `run_app.bat` 더블클릭 또는:
  ```powershell
  python main.py
  ```
- **macOS / Linux**:
  ```bash
  python main.py
  ```
