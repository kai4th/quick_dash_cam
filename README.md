# 🚗 QuickDashCam (액션캠·블랙박스 주행 영상 스마트 병합 & AI 구간 스킵)

자동차 대시보드에 설치한 액션캠(GoPro, DJI Osmo Action, Insta360, 일반 블랙박스 등)의 여러 주행 영상들을 **시간순으로 자동 정렬**하고, **신호대기(정차)**나 **장시간 고속도로 직진**처럼 화면 변화가 거의 없는 구간을 자동으로 감지하여 **배속(타임랩스) 또는 점프컷(잘라내기)** 처리해 하나의 깔끔한 완성본 영상으로 합쳐주는 크로스 플랫폼 데스크톱 애플리케이션입니다.

---

## 🧭 화면 구성 (작업 순서)

상단 단계 탭으로 화면을 바꿉니다. 진행률(경과·남은 시간)·취소·결과 폴더는 모든 화면 맨 아래 상태 줄에 있고, `F1`(또는 `⌨ 단축키` 버튼)로 지금 화면의 단축키를 볼 수 있습니다.

- **작업 자동 저장 · 이어하기**: 영상 목록, 구간 편집, 리뷰 결정, 쇼츠 컷(사용 여부·AI 설명·컷 범위·기울기·소실점)이 `~/.quick_dash_cam/session.json`에 자동 저장되고,
  다음 실행 때 "지난 작업을 이어서 할까요?"로 그대로 복원됩니다. 분석 결과는 디스크 캐시에서 바로 불러오므로 다시 분석하지 않습니다.
  옮겨지거나 지워진 영상은 빼고 복원하며, '아니요'를 눌러도 이전 작업은 `session.previous.json`으로 보관됩니다.
- **설정 기억**: 각 화면의 설정값, 마지막으로 연 폴더, 배경음악·제목이 `settings.json`에 저장됩니다.
- 작업 중에 창을 닫으면 확인한 뒤 작업을 취소하고 종료합니다.

| 화면 | 하는 일 | 주요 조작 |
|---|---|---|
| **① 영상** | 폴더·파일 추가, 촬영 시각 순 정렬, 순서 정리, 영상 정보 확인 | 썸네일 목록 · ▲▼ 순서 · `Del` 제외 |
| **② 편집** | 큰 플레이어로 탐색, 타임라인 구간 편집, 자동 구간 분석, 검출 구간 리뷰 | `Space` 재생 · `←/→` 1초(Shift 5초) · `I`/`O` 시작·끝점 · `Del` 삭제 · `Ctrl+Z` 되돌리기 · `1/2/3` 스킵·일반·삭제 · `N`/`P` 다음·이전 구간 · `R` 다시 재생 · `[`/`]` 구간 경계를 현재 위치로 · `+`/`-`/`0` 타임라인 확대·축소·전체 |
| **③ 합치기** | 정차·직진 구간 배속/삭제 방식, 화질·해상도·코덱·소리 설정, 원본 → 예상 길이 확인 후 MP4 저장 | [🎬 영상 합치기 시작] |
| **④ 쇼츠** | 하이라이트 장면 찾기(알고리즘/Claude), 컷 확인·사용/제외, 컷 범위 조정, 컷별 기울기·소실점 맞춤, 결과 화면 미리보기, 쇼츠 설정 후 만들기 | `Space` 컷 재생 · `X` 사용/제외 · `PgUp`/`PgDn` 이전·다음 컷 · `,`/`.` 컷 0.5초 앞·뒤로 · `←/→` 기울기 0.1°(Shift 1°) · 미리보기 클릭 = 소실점 |

## ✨ 주요 기능

### 1. 📂 스마트 시간순 자동 정렬 (`src/sorter.py`)
- 영상 컨테이너 메타데이터의 `creation_time` 촬영 시각, 파일명 내 날짜 패턴(`VID_YYYYMMDD_HHMMSS`), 파일 수정 시각을 종합 분석하여 정확한 시간순으로 자동 정렬합니다.
- **고프로(GoPro) 분할 챕터 완벽 대응**: `GX010042.MP4`, `GX020042.MP4`처럼 챕터 번호가 앞에 붙는 액션캠 파일명 규칙을 자동 인식하여 촬영 순서대로 정렬합니다.
- GUI 목록에서 항목 선택 후 위/아래(`▲`/`▼`) 버튼으로 언제든 수동 순서 조정 및 개별 파일 제외가 가능합니다.

### 2. ⚡ 초고속 하드웨어 가속 & 2중 화면 변화 감지 (`src/analyzer.py`, `src/ffmpeg_utils.py`)
- **GPU 디코딩 & VRAM 내부 리사이징 (`CUDA NVDEC + scale_cuda` / `D3D11VA` / `VideoToolbox` / `VAAPI`)**:
  - 4K/2.7K/1080p 고해상도 영상을 하드웨어 가속으로 디코딩하며, GPU 메모리 내부에서 `160×90` 축소 처리를 진행하여 CPU 점유율을 획기적으로 낮추고 분석 속도를 극대화했습니다.
  - 비참조 B-프레임 스킵(`-skip_frame noref`) 및 1초당 1~2프레임 다운샘플링 분석.
- **신호대기 / 정차 감지 (`STOP`)**:
  - 하늘 및 보닛/대시보드를 마스킹하고 근거리 노면/차선 영역(ROI)의 픽셀 변화량과 위상 상관을 분석하여, 교차로에 횡단 차량이나 보행자가 지나가더라도 내 차가 정차 중이면 정확하게 정차 구간으로 판별합니다.
- **고속도로 직진 / 단조 주행 감지 (`STRAIGHT`)**:
  - 차량 주행 중 수평 조향 변화량, 전방 소실점(Vanishing Point), 16×9 저주파 구도 변화량을 종합 추적하여 급커브나 차선 변경이 없는 단조로운 직선 도로 주행 구간을 자동 감지합니다.
- **민감도 실시간 즉시 재분류**:
  - 최초 1회 영상 분석 후 프레임별 변화량 점수가 메모리에 캐싱되므로, 감지 민감도(%)나 최소 지속 시간(초) 슬라이더를 변경하면 영상을 재스캔할 필요 없이 **즉시(0.01초)** 구간이 다시 계산됩니다.

### 3. 🎬 실시간 스트리밍 재생 & 타임라인 줌/패닝 (`src/ui/player.py`, `src/ui/timeline.py`)
- **실시간 순차 스트리밍 프리뷰 (`PlaybackWorker`)**:
  - 프레임 건너뜀 없이 일반 동영상 플레이어처럼 30fps 부드러운 실시간 재생을 지원합니다.
  - `0.5x`, `1.0x (기본)`, `2x`, `4x`, `8x` 배속 재생 프리뷰 선택 지원.
- **타임라인 확대/축소 및 이동 (Zoom & Pan)**:
  - 마우스 휠 스크롤로 타임라인 확대/축소 (`1배 ~ 최대 100배`), 마우스 휠 클릭 드래그 또는 `Shift + 휠`로 좌우 패닝.
  - 상단 미니맵 내비게이션 바를 통해 2시간 이상의 장시간 주행 영상에서도 원하는 위치를 한눈에 파악하고 즉시 이동할 수 있습니다.

### 4. 🔎 검출 구간 리뷰 워크플로우 (② 편집 화면 오른쪽 `검출 구간 리뷰`)
- 감지된 신호대기 및 단조 주행 구간들을 순서대로 탐색하며 사용자가 직접 유지/복원/삭제 여부를 결정할 수 있습니다. 구간을 고르면 타임라인이 그 부분으로 확대되고 앞뒤 2초를 포함해 재생됩니다.
- **키보드 단축키**:
  - `1`: 스킵 유지 · `2`: 1배속 일반 주행 복원 · `3`: 완전 삭제 (결정 후 다음 미검토 구간으로 자동 이동)
  - `N` / `P`: 다음 / 이전 구간, `R`: 현재 구간 다시 재생
  - `[` / `]`: 현재 재생 위치를 구간의 시작점 / 끝점으로 조정

### 5. ✂️ 통합 타임라인 구간 편집 & 수동 컷
- 타임라인 바 우클릭 드래그(또는 `Shift + 좌클릭 드래그`), 또는 `[🚩 시작점(I)]` / `[🏁 끝점(O)]` 버튼을 통해 특정 구간을 지정할 수 있습니다.
- `[✂️ 선택 구간 잘라내기 (Delete)]`로 불필요한 사생활 노출 구간이나 주차 영상을 즉시 삭제 처리할 수 있습니다.
- `[♻️ 일반 주행(1x) 복원]`으로 자동 감지된 스킵 구간을 일반 주행으로 되돌릴 수 있으며, `[↩ 되돌리기 (Ctrl+Z)]`를 지원합니다.

### 6. 🎛️ 풍부한 인코딩 & 내보내기 옵션 (`src/processor.py`)
- **화질 프리셋**:
  - `원본 유지급 최고화질 (무손실에 가까움 · CRF 14 / CQ 15, 오디오 256kbps)`
  - `고화질 (원본 수준 권장 · CRF 18 / CQ 19, 오디오 192kbps)`
  - `표준 화질 (화질·용량 균형 · CRF 22 / CQ 23)`
  - `저용량·고속 (빠른 압축 · CRF 27 / CQ 28)`
- **해상도**: `원본 해상도 유지`, `4K UHD (3840×2160)`, `2.7K QHD (2560×1440)`, `1080p FHD`, `720p HD`
- **프레임 레이트**: `원본 FPS 유지`, `60fps`, `30fps`, `24fps`
- **비디오 코덱**: `H.264 (AVC - 호환성 최우선)`, `H.265 / HEVC (고효율·4K 압축 권장)`
- **오디오 처리**:
  - 정상 구간 유지 / 스킵 구간 음소거
  - 배속 구간도 오디오 속도 높여 함께 재생 (`atempo` 음높이 보정)
  - 전체 음소거
- **배속 배지 오버레이**: 배속 재생 구간 우측 상단에 반투명 박스 및 `>> 8x` 배지 표시 지원.

### 7. 🎬 하이라이트 쇼츠 자동 생성 (`src/highlights.py`, ④ 쇼츠 화면)
- 긴 주행 영상 전체에서 **볼 만한 순간만 자동으로 골라 15~90초 길이의 쇼츠 영상**으로 만들어 줍니다.
- **컷 품질 = 컷 안에서 차분할 것**: 3초 컷 안에서 화면이 크게 바뀌면(좌·우회전, 주차장 출입, 터널 진출입, 급변) 쇼츠가 어지러우므로,
  구간 분석 때 캐싱된 특징값으로 "차가 안정적으로 앞으로 달리는 정도"를 계산합니다 (추가 디코딩 없음).
  - 회전 중인 순간은 제외, 급격한 화면 변화·과도한 변화량은 감점, 아주 느린 주행(주차장·골목)은 감점
  - 3초 중 일부에만 회전·감속이 섞여도 감점되도록 컷의 평균과 최저값을 함께 반영, 너무 불안정한 컷은 아예 쓰지 않음
  - 신호대기·정차 순간이 섞인 컷과 수동 잘라내기 구간은 **자동 제외**, 고속도로 순항은 감점 없이 반영
- **장면 선정 — 컷끼리 배경이 겹치지 않게**: 컷 안에서는 차분하되 컷들끼리는 서로 달라 보이는 것이 중요합니다.
  - 구간 분석 때 2초마다 작은 썸네일(색 분포·화면 구도)을 함께 저장하고(추가 디코딩 없음), 이미 고른 컷들과 **가장 달라 보이는 장면**을 다음 컷으로 고릅니다. 거의 같은 모습의 컷은 개수가 모자라도 넣지 않습니다.
  - 주행의 **출발 직후·도착 직전 약 3분**(주차장·골목일 가능성이 높음)과 **너무 어두운 장면**(지하주차장 등)은 크게 감점하고, 컷 사이에 최소 시간 간격을 둡니다.
  - 최종 컷은 **시간순 정렬**됩니다.
- 목록에서 장면 클릭 시 해당 장면 즉시 재생, `[▶ 전체 미리보기]`로 완성본 순서대로 이어 보기, 더블클릭 또는 `[X]`로 장면 포함/제외.
- **출력 옵션**:
  - 화면: `세로 9:16 · 흐림 배경` (가로 영상 전체 + 위아래 블러 배경, 권장) / `세로 9:16 · 꽉 채우기` (중앙 크롭) / `가로 16:9`
  - 해상도: `자동 (원본 화질)` (4K 원본 → 2160×3840, 1440p 원본 → 1440×2560, 그 외 1080×1920) / `4K` / `1440p` / `1080p` / `720p`
    - 세로 흐림 배경 레이아웃은 가로 영상이 화면 폭에 맞춰 들어가므로, 4K 원본이라면 4K 세로로 만들어야 영상 부분이 2160×1215로 원본 디테일이 살아납니다.
  - 프레임레이트: `원본 fps` (최대 60fps, 기본) / `60fps` / `30fps`
  - **컷별 화면 맞춤 (수동)**: 왼쪽 장면 목록에서 컷을 고르면 가운데 큰 미리보기에 그 컷이 표시되고, 바로 아래 조작 줄에서 조정합니다.
    - `↺ / ↻ 0.5°`: 그 컷의 기울기를 직접 맞춤 (짐벌캠처럼 컷마다 각도가 다를 수 있는 영상용)
    - 미리보기에서 도로가 한 점으로 모이는 곳을 클릭하면 소실점 지정: 모든 컷의 소실점이 같은 위치(가로 중앙, 높이는 컷들의 중앙값)에
      오도록 화면을 옮겨, 컷이 바뀌어도 도로가 같은 곳으로 뻗어 화면이 안정돼 보이게 합니다.
    - 회전·이동 후 가장자리에 빈 공간이 생기지 않도록 필요한 만큼만 자동 확대(최대 2배)하며, 미리보기에 결과와 기준선(격자·중앙선·목표 소실점)이 바로 표시됩니다.
      미리보기와 실제 렌더링은 같은 계산을 사용합니다. `이 컷 초기화`로 되돌릴 수 있고, 목록의 `맞춤` 열에 조정 내용이 표시됩니다.
    - 수동으로 맞춘 컷은 자동 수평 보정보다 우선합니다. `전체 적용`으로 현재 컷의 기울기를 사용 중인 모든 컷에 한 번에 줄 수 있습니다.
  - **컷 범위 조정**: `◀ 0.5초 / 0.5초 ▶`로 컷을 앞뒤로 옮기고, `길이 −/+0.5초`로 1~8초 사이에서 길이를 바꿉니다.
  - **📱 결과 화면 미리보기**: 가운데 미리보기를 실제 결과 모습(세로 9:16 흐림 배경 / 꽉 채우기 / 가로 16:9)으로 바꿔,
    제목·자막·촬영 시각이 놓일 위치까지 만들기 전에 확인합니다.
  - **수평 자동 보정 (실험적, 기본 꺼짐)**: 시골길·전선이 많은 장면에서는 추정이 틀려 오히려 기울일 수 있고, 짐벌 영상은 원래 수평이라 기본으로 꺼져 있습니다.
    건물·전봇대·지평선 같은 수평/수직 직선으로 카메라 기울기를 추정해, 반대로 회전한 뒤 모서리 빈 공간이 안 보이게 살짝 확대·크롭합니다
    (2° 보정 ≈ 6% 확대. 4K 원본은 4K 그대로 회전한 뒤 줄이므로 화질 손실은 거의 없음).
    - **컷마다** 그 구간의 프레임 5장으로 각도를 정하고 컷 안에서는 고정합니다 (주행 중 카메라가 돌아갔거나 경사로에서 기운 컷도 대응).
    - 컷 단위 판단이 어려우면, 영상 전체 프레임의 75% 이상이 같은 각도일 때만 그 값을 쓰고, 아니면 그대로 둡니다 (잘못 돌리는 것보다 안전).
    - 광각 렌즈 왜곡에 대비해 화면 중앙의 직선을 더 신뢰하고, 휘어 보이는 화면 맨 아래(보닛·대시보드)는 제외합니다.
    - 컷별 적용 각도는 완료 창에 표시됩니다.
  - 소리: `원본 주행 소리` / `배경음악만` / `원본 + 배경음악` (음악은 길이에 맞춰 자동 반복·페이드 아웃) / `무음`
  - 장면 전환: `크로스 디졸브`(앞뒤 컷이 겹치며 섞임, 소리도 크로스페이드, 기본) / `검은 화면 페이드` / `바로 컷`, 전환 길이 0.3~1.0초.
    겹치는 만큼 쇼츠가 짧아지지 않도록 각 컷을 전환 길이만큼 늘려 렌더링하고, 쇼츠 맨 처음·맨 끝은 페이드 인/아웃합니다.
  - 화면 상단 제목(한글 지원), 장면별 실제 촬영 시각 표시
  - 화질 등급과 GPU 인코딩 여부는 ④ 쇼츠 화면의 `화면` 설정에서 고릅니다.

### 8. 🤖 Claude AI 장면 선정·편집 (`src/ai_director.py`)
- 알고리즘은 "화면이 얼마나 변하는지"만 알기 때문에, **Claude가 실제 장면 사진을 보고 최종 장면을 고르도록** 할 수 있습니다.
- 동작 방식:
  1. 알고리즘이 목표 장면 수의 약 5배(20~80개) 후보를 **서로 다른 모습 위주로** 넉넉히 뽑습니다 (30초 쇼츠 = 10컷 → 후보 50개).
  2. 후보마다 시작·중간·끝 3프레임을 번호와 함께 한 줄로, 6개씩 한 장의 사진으로 묶습니다 (전송량·비용 절감).
  3. Claude가 후보별 점수(0~10)·장면 설명·자막과 최종 장면을 정해 줍니다 (안정적으로 달리는 경치 좋은 장면 선호, 좌·우회전·주차장·정체·어두운 장면·비슷한 장면 회피, 후보 사진 3장이 크게 다르면 회전 중으로 보고 제외).
  4. 선택되지 않은 후보도 목록에 남아 있어 `X`(또는 더블클릭)로 바꿔 넣을 수 있습니다. 제목은 직접 입력했을 때만 들어갑니다.
- ④ 쇼츠 화면 오른쪽 `장면 선정`의 **고르는 방법**에서 방식을 고릅니다.
  - `Claude Code (구독 계정)`: PC에 설치·로그인된 Claude Code(`claude` 명령)를 백그라운드로 실행합니다. 별도 API 키나 과금 없이 구독 사용량으로 동작합니다.
  - `Claude API (API 키)`: Anthropic API를 직접 호출합니다 (`ANTHROPIC_API_KEY` 환경 변수 또는 실행 중 입력, 파일에 저장하지 않음). 후보 50개 기준 1회 약 수백 원 수준입니다.
  - `알고리즘 (빠름·오프라인)`: 기존 방식.
- AI 호출이 실패하면(미설치·미로그인·네트워크 오류 등) 실제 오류 메시지와 해결 방법을 알려 주고 알고리즘 결과로 대신 표시합니다.
- `Claude Code (구독 계정)` 방식은 PC에 `ANTHROPIC_API_KEY` 환경 변수가 있어도 무시하고 구독 로그인으로 실행합니다. 처음 한 번은 터미널에서 `claude`를 실행해 로그인해야 합니다 (Claude 데스크톱 앱·웹 로그인과 별개).
- ⚠️ AI 방식은 후보 장면 사진(저해상도)이 Anthropic 서버로 전송됩니다. 처음 사용할 때 확인 창이 표시됩니다.
- `글자` 설정의 `AI 장면 자막`을 켜면 Claude가 붙인 짧은 자막("해 질 무렵", "한산한 국도"처럼 담백한 명사구, 어울리는 말이 없으면 생략)이
  영상 왼쪽 아래 구석에 작은 보통 굵기 글씨로 표시됩니다. 자막과 촬영 시각은 디졸브로 겹치는 구간을 피해 컷 중간에만 서서히 나타났다 사라집니다.

## 🖥️ 플랫폼 지원 (Cross-Platform)

QuickDashCam은 Windows, macOS, Linux 전 플랫폼에서 동일하게 동작합니다.

- **Windows**: NVIDIA CUDA/NVDEC/NVENC, Direct3D 11 (`d3d11va`), Intel QSV, AMD AMF
- **macOS**: Apple Silicon (M1~M4) 및 Intel Mac의 **VideoToolbox** (`h264_videotoolbox`, `hevc_videotoolbox`)
- **Linux**: NVIDIA NVENC 및 Intel/AMD **VAAPI** (`h264_vaapi`, `hevc_vaapi`)
- **CPU 폴백**: 하드웨어 가속 장치가 없는 환경에서도 멀티스레드 CPU 코덱(`libx264`, `libx265`)으로 100% 정상 완주

## 🚀 설치 및 실행 방법

### 요구 사항
- Python 3.9 이상
- Windows 10/11, macOS 12+, 또는 Linux

### 1. 저장소 복제 (Clone)
```bash
git clone https://github.com/kai4th/quick_dash_cam.git
cd quick_dash_cam
```

### 2. 가상환경 생성 및 의존성 설치
- **Windows**:
  ```powershell
  python -m venv .venv
  .venv\Scripts\activate
  pip install -r requirements.txt
  ```
- **macOS / Linux**:
  ```bash
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  ```

### 3. 프로그램 실행
- **Windows**: 폴더 내 `run_app.bat` 더블클릭 또는:
  ```powershell
  python main.py
  ```
- **macOS / Linux**:
  ```bash
  python main.py
  ```
